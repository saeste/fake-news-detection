# Fake News Detection

Пројекат имплементира систем за детекцију лажних вести применом техника обраде природног језика (NLP) и машинског учења. Циљ пројекта је класификација новинских чланака на истините и лажне вести на основу њиховог текстуалног садржаја.

## Процес обраде обухвата:
- експлоративну анализу података (EDA),
- чишћење и претпроцесирање текста,
- екстракцију карактеристика применом TF-IDF методе,
- обучавање и поређење модела Multinomial Naive Bayes и Random Forest,
- евалуацију перформанси модела помоћу метрика као што су тачност (Accuracy), - прецизност (Precision), одзив (Recall) и F1 мера.

За обучавање и тестирање коришћен је скуп података који садржи истините и лажне вести преузете са Kaggle платформе.

# Покретање пројекта

## 1. Инсталација зависности

Инсталирајте све потребне библиотеке:
pip install -r requirements.txt

## 2. Преузимање скупа података

Преузмите податке са следећег линка:
https://www.kaggle.com/datasets/bhavikjikadara/fake-news-detection

## 3. Постављање података

Унутар директоријума пројекта fake-news-detection направите фасциклу:
data/

У фасциклу data копирајте следеће датотеке:
- true.csv
- false.csv

## 4. Извршавање notebook-ова

Покрените notebook-ове следећим редоследом:

### 4.1 Експлоративна анализа података

Покрените све ћелије:
01_eda.ipynb

### 4.2 Чишћење и претпроцесирање података

Након успешног завршетка претходног notebook-а покрените:
02_cleaning_preprocessing.ipynb

### 4.3 TF-IDF векторизација

Након успешног завршетка претходног notebook-а покрените:
03_tfidf.ipynb

Проверите да ли су креиране следеће датотеке:
- X_train.npz
- X_test.npz
- y_train.npy
- y_test.npy
- tfidf_vectorizer.joblib

Уколико нека датотека недостаје, поново покрените последњу ћелију notebook-а 03_tfidf.ipynb.

### 4.4 Тренирање модела

Након успешног завршетка претходног notebook-а покрените:
04_naive_bayes_random_forest.ipynb

Проверите да ли су креиране следеће датотеке:
- nb_model.joblib
- rf_model.joblib

Уколико нека датотека недостаје, поново покрените последњу ћелију notebook-а 04_naive_bayes_random_forest.ipynb.

### 4.5 Евалуација модела

На крају покрените:
05_evaluation.ipynb

Након успешног извршавања овог notebook-а биће приказани резултати евалуације обучених модела.
